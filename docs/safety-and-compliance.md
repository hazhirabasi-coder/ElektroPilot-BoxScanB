# Safety and compliance gate

This is a project checklist, not legal or engineering certification.

Before any mains-connected prototype:
- Define intended use and installation environment.
- Select certified, appropriately rated measurement equipment.
- Have the isolation/protection design reviewed by a qualified electrical engineer.
- Review applicable DIN/VDE requirements, relevant IEC/EN standards, EMC, electrical safety, enclosure, temperature, fire, creepage/clearance, overvoltage category, pollution degree and installation category.
- Define safe states, fault handling, fusing, surge protection, enclosure and service procedure.
- Perform documented bench tests with safe low-voltage sources before any field evaluation.
- Conduct risk assessment and independent review before deployment.

Never claim that software output proves a circuit, RCD, protective conductor, or installation is safe. Never work live based only on app guidance.
